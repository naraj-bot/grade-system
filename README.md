# ระบบตัดเกรด โรงเรียนขยายโอกาส (ป.1-ม.3)

Vite + React + Firebase (Auth, Firestore) โฮสต์บน Vercel

## ตั้งค่าครั้งแรก
1. สร้างโปรเจกต์ Firebase เปิด Authentication (Email/Password) และ Firestore
2. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่า `VITE_FIREBASE_*`
3. สร้าง Service Account (Project settings > Service accounts) แล้วตั้งค่า `FIREBASE_ADMIN_*` ใน Vercel
4. วาง `firestore.rules` ใน Firestore > Rules
5. สร้างแอดมินหลักคนแรก: `node scripts/create-superadmin.mjs อีเมล รหัสผ่าน "ชื่อ-สกุล"`
6. `npm install && npm run dev`

## ที่ทำแล้ว
- เข้าสู่ระบบ 3 บทบาท (แอดมินหลักใช้อีเมล ครูใช้ชื่อผู้ใช้) บังคับเปลี่ยนรหัสครั้งแรก
- แอดมินหลักรีเซ็ตรหัสผ่าน, สร้างบัญชีครู/แอดมินโรงเรียน (`/api/users`)
- เปิด/ปิดปีการศึกษาและภาคเรียน
- ข้อมูลคลังรายวิชาตั้งต้น 159 รายการ: `src/data/catalog.json`

## ขั้นถัดไป
นักเรียนและเลื่อนชั้น > คลังและเปิดรายวิชา > ลงทะเบียนสอน/อนุมัติ > กรอกคะแนน > กิจกรรมพัฒนาผู้เรียน > ส่งออก Excel/Word/PDF

## สิ่งที่มีในระบบ
- หน้าแรก (landing) + ล็อกอิน, เปลี่ยนรหัสผ่านครั้งแรก, ธีมแดง-ทอง, เมนูข้าง/แถบล่างบนจอเล็ก, เครดิต "พัฒนาโดย ครูซอสสอนสังคม"
- ปีการศึกษา/ภาคเรียน, ผู้ใช้ (แอดมินหลัก/แอดมินโรงเรียน/ครู) พร้อมพิมพ์ใบรหัสผ่านเริ่มต้น
- นักเรียน (เฉพาะแอดมิน): เพิ่มทีละคน/วางหลายคน/นำเข้า Excel-CSV, แก้ไข, ย้ายออก/จบ, เลื่อนชั้นอัตโนมัติ, ประวัติแก้ไข
- รายวิชา: แอดมินเปิดสอนต่อปี → ครูลงทะเบียนสอน → แอดมินอนุมัติ/ส่งกลับ
- กรอกคะแนน: สัดส่วน 60:40/70:30/80:20 ต่อวิชา, หลายช่องคะแนน/หน่วยการเรียนรู้, ประถมเก็บ 100 (ย่อ 50) หรือ 50 ต่อภาค, กรอกเฉพาะชั่วโมงที่ขาด, มส. (<80%), ร, เกรด 0–4
- ประเมินผู้เรียน (คุณลักษณะ / อ่านคิดวิเคราะห์เขียน / สมรรถนะ) — ปพ.5 ลงนามและดาวน์โหลดถูกล็อกจนกว่าจะประเมินครบ
- กิจกรรมพัฒนาผู้เรียน (แนะแนว/ลูกเสือ/สังคมฯ ตามสิทธิ์ครูที่ปรึกษา/ครูแนะแนว, ชุมนุมสร้างได้หลายชุมนุม เลือกสมาชิกทั้งโรงเรียน)
- สมุด ปพ.5 (A4 แนวตั้ง, TH Sarabun, ประถมเล่มเดียวต่อปี แยกหน้าภาค 1/ภาค 2/สรุปทั้งปี): ดาวน์โหลด PDF (พิมพ์เป็น PDF), Word (.doc), Excel (.xls)
- ใบแจ้งผลการเรียน (ประถมภาค 1 / ภาค 2 / มัธยม) รายคนหรือทั้งห้อง ลงนามครูที่ปรึกษา/ผอ.
- ลายเซ็นอิเล็กทรอนิกส์ (วาดหรือแนบ), ตั้งค่าโรงเรียน/ผู้ลงนาม/หัวหน้ากลุ่มสาระ/ครูที่ปรึกษาประจำชั้น, คู่มือใช้งาน

- กระดิ่งแจ้งเตือน (ส่งลงทะเบียน/อนุมัติ/ส่งกลับ/มีคนกรอกกิจกรรมห้องแล้ว), สรุปผลรายห้อง (PDF + Excel) สำหรับแอดมินและครูที่ปรึกษา, ปุ่ม Excel เป็นไฟล์ .xlsx จริง, เข้าสู่ระบบด้วย Google (แอดมินที่ผูกบัญชีแล้ว)

## ข้อมูลใน Firestore
users, years, students, studentLog, subjectOpen, registrations, work (คะแนน/ค่าตั้ง/ประเมิน/กิจกรรม แยกเอกสารต่อวิชา id = ปี~หมวด~คีย์), sigs (ลายเซ็น), settings/school

## ต้องทำหลังอัปเดต
1. `npm install && npm run build` (หรือ `npm run dev`)
2. คัดลอก `firestore.rules` ไปวางใน Firebase Console → Firestore → Rules แล้ว Publish
3. ทดสอบ: เข้าแอดมิน → ตั้งค่าโรงเรียน (ชื่อผู้ลงนาม + ครูที่ปรึกษาประจำชั้น) → นักเรียน → รายวิชา → ครูลงทะเบียน → แอดมินอนุมัติ → ครูกรอกคะแนน/ประเมิน → ปพ.5

## ข้อจำกัดที่ควรรู้
- ปุ่ม PDF: คอม/โน้ตบุ๊กเปิดหน้าต่างพิมพ์ให้เลือก "บันทึกเป็น PDF" (ต้องอนุญาต pop-up) ส่วนไอแพด/มือถือให้เซิร์ฟเวอร์ (`api/pdf.js` ใช้ Chromium บน Vercel) สร้างไฟล์ PDF ให้ดาวน์โหลดตรง ถ้าเซิร์ฟเวอร์สร้างไม่ได้จะให้กดปุ่มอีกครั้งเพื่อใช้วิธีพิมพ์แทน
- กฎ Firestore: ข้อมูลวิชา (`work`) เขียนได้เฉพาะแอดมินหรือครูที่ได้รับอนุมัติวิชานั้น แต่ทุกคนที่ล็อกอินยังอ่านได้ และข้อมูลกิจกรรม/ชุมนุม/ใบแจ้งผลเขียนได้ทุกคนที่ล็อกอิน
- Word เป็นไฟล์ HTML นามสกุล .doc

- สำรองข้อมูล: เมนู "สำรองข้อมูล" (แอดมิน) ดาวน์โหลดข้อมูลทั้งระบบเป็นไฟล์ JSON; แอดมินหลักกู้คืนจากไฟล์ได้ (ไม่กู้บัญชีผู้ใช้และประวัติแก้ไขนักเรียน)
- Word: ไฟล์ .docx จริง (ตาราง/ย่อหน้า/รูป) เปิดได้ใน Word, WPS, LibreOffice, Google เอกสาร ฟอนต์ TH SarabunPSK ต้องมีในเครื่องที่เปิดไฟล์
- ยังไม่มีปีการศึกษาที่เปิด: ทุกเมนูยังเปิดดูได้ (โหมดแบบฟอร์ม) ดาวน์โหลดฟอร์มเปล่า ปพ.5/ใบแจ้งผล/สรุป ได้ แต่กรอกหรือแก้ข้อมูลไม่ได้
- หน้าผู้ใช้: เพิ่มหลายคนพร้อมกัน (บรรทัดละคน) สุ่มรหัสผ่านเริ่มต้นและพิมพ์ใบรหัสได้
- นักเรียน: เลขประจำตัว (ไม่บังคับ) กรอก/วางรายชื่อ/นำเข้า Excel ได้ และขึ้นในใบแจ้งผลการเรียน
- แก้บั๊ก: ตัวฟัง settings/sigs ของเอนจินไม่ถูกยกเลิกตอนเปิดรับข้อมูลรายปี
- บัญชีครู (แอดมินหลัก): แก้ชื่อ/บทบาท ปิด-เปิดใช้งาน ลบบัญชี รีเซ็ตรหัสพร้อมกล่องแสดงรหัส (คัดลอก/บันทึกเป็นภาพรายบุคคล) — ผ่าน /api/users

- ใบแจ้งผลมัธยม: เปลี่ยนเป็น "แบบรายงานประจำตัวนักเรียน" หน้าเดียว A4 (หน่วยกิต สอบปกติ/แก้ตัว คุณลักษณะ อ่านคิดวิเคราะห์เขียน สรุปหน่วยกิต/GPA ถ่วงหน่วยกิต) มีสวิตช์ "แสดงคะแนนรวมในใบแจ้งผล" ต่อชั้น ไม่มีลำดับที่ในห้อง
- แก้บั๊ก: หน้าความคืบหน้า/คะแนนพัง "Cannot read properties of undefined (reading length)" เมื่อค่าตั้งวิชาหรือเช็คชื่อที่บันทึกเป็นค่าเริ่มต้น ({}) ถูกโหลดกลับจาก Firestore
- ใบแจ้งผลประถมใช้แบบเดียวกับมัธยม ("แบบรายงานประจำตัวนักเรียน" หน้าเดียว A4) ทั้งภาค 1 (คะแนนเต็ม 50 ยังไม่ตัดเกรด) และภาค 2 (ผลทั้งปี) ประถมใช้ "น้ำหนัก" = ชั่วโมงทั้งปี ÷ 40 · ใบแจ้งผลไม่แสดงเวลาเรียนแล้ว
- ตัดเกรดจากคะแนนรวมที่ปัดเป็นจำนวนเต็ม (x.5 ปัดขึ้น) และใบแจ้งผลแสดงคะแนนเป็นจำนวนเต็ม
- หน้าความคืบหน้า: ปุ่ม "เปิด" เปลี่ยนเป็น "ดูคะแนน"/"กรอกคะแนน" และแก้บั๊กแอดมินกดแล้วไปไม่ถึงวิชาของครูคนอื่น (เมื่อแอดมินลงทะเบียนสอนเองหรือวิชายังไม่ได้ติ๊กเปิดสอน)
- แก้บั๊กครู "ยกเลิกการส่ง" แล้วขึ้นไม่มีสิทธิ์: กฎ Firestore ให้ครูลบเอกสารของวิชาที่ตนสอนได้ (ต้องเผยแพร่ firestore.rules ใหม่) และหน้าเว็บคืนสถานะเดิมเมื่อลบไม่สำเร็จ
- ลงทะเบียนสอน: ครูที่อนุมัติแล้วกด "แก้ไขการลงทะเบียน" เพื่อขอเพิ่ม/เอาวิชาออกได้ (เก็บใน reqCodes) วิชาเดิมใช้งานได้ระหว่างรอ แอดมินอนุมัติ/ส่งกลับคำขอได้ (ต้องเผยแพร่ firestore.rules ใหม่)
- เข้าสู่ระบบด้วย Google: แจ้งเตือน/ปุ่มเปิดใน Safari-Chrome เมื่ออยู่ในเบราว์เซอร์ของแอป (LINE, Facebook ฯลฯ) และเพิ่ม rewrite /__/auth/* ใน vercel.json (ใช้คู่กับตั้ง VITE_FIREBASE_AUTH_DOMAIN เป็นโดเมนเว็บ)
- เปลี่ยนชื่อระบบเป็น "ระบบงานวัดผล" (ชื่อแท็บ แถบเมนู ท้ายเว็บ หน้าแรก บัตร/แผ่นบัญชีผู้ใช้ ชื่อไฟล์สำรองข้อมูล)
- เปลี่ยนชื่อระบบเป็น "ระบบผลการเรียน" (ชื่อเต็มท้ายเว็บ: ระบบบันทึกและประกาศผลการเรียน) และหน้าต่างเข้าสู่ระบบเป็นแบบพื้นหลังเบลอ
- หน้าประเมินคุณลักษณะ/อ่านคิดวิเคราะห์เขียน: แสดงเป็นตารางเดียวเสมอ (เลิกแบ่ง 2 ฝั่งบนจอกว้าง) หัวตารางค้างด้านบน
- หน้าความคืบหน้า: วิชาที่มีการกรอกคะแนน/ส่งผลแล้วแต่ไม่มีใบลงทะเบียนสอน แสดงความคืบหน้าจริง ชื่อผู้ส่งผล และป้าย "ยังไม่ลงทะเบียนสอน" แทน "ยังไม่มีครูสอน"
- ระบบนักเรียนดูผลการเรียนออนไลน์:
  - หน้าแรกใหม่ (จบในหน้าเดียว) ชื่อ "ระบบผลการเรียน" ปุ่มนักเรียน/ครูเปิดหน้าต่างพื้นหลังเบลอ แสดงสถานะประกาศผลและประกาศล่าสุด
  - /student นักเรียนกรอกเลขประจำตัวด้วยแป้นตัวเลข ดูเกรด GPA ผลประเมิน กิจกรรม และพิมพ์/บันทึกใบแจ้งผล PDF (ไม่ต้องล็อกอิน)
  - เมนู "เผยแพร่ผลการเรียน" (แอดมิน): เลือกสิ่งที่นักเรียนเห็น เผยแพร่/เผยแพร่ใหม่/ยกเลิกรายชั้น สถานะ "มีการแก้ไขหลังเผยแพร่"
  - เมนู "ประกาศหน้าแรก" (แอดมิน): เพิ่ม/ปักหมุด/ซ่อน/ลบประกาศ
  - api/student-result.js อ่านผลด้วย Admin SDK กันสุ่มเลข (ผิดเกิน 10 ครั้ง/15 นาที/IP)
  - Firestore: news, publishMeta (อ่านได้ทุกคน), published (แอดมิน), rl (ปิด) — ต้องเผยแพร่ firestore.rules ใหม่
- สรุปผลรายห้อง: ช่องที่ยังไม่มีเกรดแสดง "ไม่ครบ" พร้อมบอกว่าขาดคะแนนส่วนไหน รายการคะแนนที่ยังไม่ครบใต้ตาราง และ GPA ถ่วงด้วยหน่วยกิต/น้ำหนัก + ผลแก้ตัว ให้ตรงกับใบแจ้งผล
- แก้บั๊กกรอกคะแนนครบแต่ไม่รวม/ไม่ตัดเกรด: นับคะแนนเก็บเฉพาะช่องที่ตั้งไว้ตอนนี้ และการลบช่องคะแนนเก็บจะลบคะแนนช่องนั้นของทุกคนด้วย (ถามยืนยันถ้ามีคะแนน)
- หน้าแรก: แก้คลาส .ph ชนกับ ปพ.5 (ข้อความเล็ก/ขีดเส้นใต้) → .nw · เพิ่มคำแนะนำ 3 ขั้นตอน · สถานะประกาศผลแสดงเสมอ · ช่องประกาศว่างแสดงข้อความ
- ชุมนุม: แอดมินสร้างและมอบหมายครูผู้สอนได้ (เปลี่ยนครูได้ มีแจ้งเตือนครู) ครูสร้างชุมนุมของตนได้ · เลือก/เอาออกทั้งชั้น · นักเรียนชนชุมนุมอื่นมีแจ้งเตือนให้เลือกย้าย และสรุปนักเรียนที่อยู่หลายชุมนุม · ประถมตัดสินผลชุมนุมในภาคเรียนที่ 2
- กิจกรรมพัฒนาผู้เรียนของประถมทุกกิจกรรม (แนะแนว ลูกเสือ-เนตรนารี กิจกรรมเพื่อสังคมฯ ชุมนุม) ตัดสินผลในภาคเรียนที่ 2
- ลายเซ็น: ลบพื้นหลังอัตโนมัติเมื่อวาด/แนบ (พิกเซลสีอ่อนโปร่งใส + ตัดขอบว่าง) มีปุ่ม "ลบพื้นหลังลายเซ็นเดิม" และแสดงแบบ multiply · คำว่า "ลงชื่อ" อยู่บนเส้นจุด ลายเซ็นลอยเหนือเส้น ไม่ดันมากึ่งกลาง

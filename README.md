# ระบบตัดเกรด โรงเรียนขยายโอกาส (ป.1-ม.3)

Vite + React + Firebase (Auth, Firestore) โฮสต์บน Vercel

## ตั้งค่าครั้งแรก
1. สร้างโปรเจกต์ Firebase เปิด Authentication (Email/Password) และ Firestore
2. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่า `VITE_FIREBASE_*`
3. สร้าง Service Account (Project settings > Service accounts) แล้วตั้งค่า `FIREBASE_ADMIN_*` ใน Vercel
4. วาง `firestore.rules` ใน Firestore > Rules
5. สร้างแอดมินหลักคนแรก: `node scripts/create-superadmin.mjs อีเมล รหัสผ่าน "ชื่อ-สกุล"`
6. `npm install && npm run dev`

## ที่ทำแล้ว
- เข้าสู่ระบบ 3 บทบาท (แอดมินหลักใช้อีเมล ครูใช้ชื่อผู้ใช้) บังคับเปลี่ยนรหัสครั้งแรก
- แอดมินหลักรีเซ็ตรหัสผ่าน, สร้างบัญชีครู/แอดมินโรงเรียน (`/api/users`)
- เปิด/ปิดปีการศึกษาและภาคเรียน
- ข้อมูลคลังรายวิชาตั้งต้น 159 รายการ: `src/data/catalog.json`

## ขั้นถัดไป
นักเรียนและเลื่อนชั้น > คลังและเปิดรายวิชา > ลงทะเบียนสอน/อนุมัติ > กรอกคะแนน > กิจกรรมพัฒนาผู้เรียน > ส่งออก Excel/Word/PDF

## สิ่งที่มีในระบบ
- หน้าแรก (landing) + ล็อกอิน, เปลี่ยนรหัสผ่านครั้งแรก, ธีมแดง-ทอง, เมนูข้าง/แถบล่างบนจอเล็ก, เครดิต "พัฒนาโดย ครูซอสสอนสังคม"
- ปีการศึกษา/ภาคเรียน, ผู้ใช้ (แอดมินหลัก/แอดมินโรงเรียน/ครู) พร้อมพิมพ์ใบรหัสผ่านเริ่มต้น
- นักเรียน (เฉพาะแอดมิน): เพิ่มทีละคน/วางหลายคน/นำเข้า Excel-CSV, แก้ไข, ย้ายออก/จบ, เลื่อนชั้นอัตโนมัติ, ประวัติแก้ไข
- รายวิชา: แอดมินเปิดสอนต่อปี → ครูลงทะเบียนสอน → แอดมินอนุมัติ/ส่งกลับ
- กรอกคะแนน: สัดส่วน 60:40/70:30/80:20 ต่อวิชา, หลายช่องคะแนน/หน่วยการเรียนรู้, ประถมเก็บ 100 (ย่อ 50) หรือ 50 ต่อภาค, กรอกเฉพาะชั่วโมงที่ขาด, มส. (<80%), ร, เกรด 0–4
- ประเมินผู้เรียน (คุณลักษณะ / อ่านคิดวิเคราะห์เขียน / สมรรถนะ) — ปพ.5 ลงนามและดาวน์โหลดถูกล็อกจนกว่าจะประเมินครบ
- กิจกรรมพัฒนาผู้เรียน (แนะแนว/ลูกเสือ/สังคมฯ ตามสิทธิ์ครูที่ปรึกษา/ครูแนะแนว, ชุมนุมสร้างได้หลายชุมนุม เลือกสมาชิกทั้งโรงเรียน)
- สมุด ปพ.5 (A4 แนวตั้ง, TH Sarabun, ประถมเล่มเดียวต่อปี แยกหน้าภาค 1/ภาค 2/สรุปทั้งปี): ดาวน์โหลด PDF (พิมพ์เป็น PDF), Word (.doc), Excel (.xls)
- ใบแจ้งผลการเรียน (ประถมภาค 1 / ภาค 2 / มัธยม) รายคนหรือทั้งห้อง ลงนามครูที่ปรึกษา/ผอ.
- ลายเซ็นอิเล็กทรอนิกส์ (วาดหรือแนบ), ตั้งค่าโรงเรียน/ผู้ลงนาม/หัวหน้ากลุ่มสาระ/ครูที่ปรึกษาประจำชั้น, คู่มือใช้งาน

## ข้อมูลใน Firestore
users, years, students, studentLog, subjectOpen, registrations, work (คะแนน/ค่าตั้ง/ประเมิน/กิจกรรม แยกเอกสารต่อวิชา id = ปี~หมวด~คีย์), sigs (ลายเซ็น), settings/school

## ต้องทำหลังอัปเดต
1. `npm install && npm run build` (หรือ `npm run dev`)
2. คัดลอก `firestore.rules` ไปวางใน Firebase Console → Firestore → Rules แล้ว Publish
3. ทดสอบ: เข้าแอดมิน → ตั้งค่าโรงเรียน (ชื่อผู้ลงนาม + ครูที่ปรึกษาประจำชั้น) → นักเรียน → รายวิชา → ครูลงทะเบียน → แอดมินอนุมัติ → ครูกรอกคะแนน/ประเมิน → ปพ.5

## ข้อจำกัดที่ควรรู้
- ปุ่ม PDF เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ ให้เลือก "บันทึกเป็น PDF" (ชื่อไฟล์ตั้งให้อัตโนมัติ) ต้องอนุญาต pop-up
- Word/Excel เป็นไฟล์ HTML นามสกุล .doc/.xls (เปิดด้วย Word/Excel ได้ อาจมีข้อความเตือนรูปแบบไฟล์)
- กฎ Firestore ของคะแนน (`work`) ตอนนี้ให้ผู้ล็อกอินเขียนได้ ควรเข้มขึ้นภายหลังให้เฉพาะครูที่ได้รับอนุมัติวิชานั้น
